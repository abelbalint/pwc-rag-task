# Software Requests

This document describes how to install approved software and how to request software that is not yet approved.

## Approved software catalog

Approved applications are available in the Software Center on every company laptop. No ticket is needed for these:

- Microsoft Office suite
- Zoom and Microsoft Teams
- Google Chrome and Mozilla Firefox
- Visual Studio Code
- 7-Zip
- Adobe Acrobat Reader

To install one, open the Software Center, search for the application, and click Install.

## Software requiring a license

Some applications need a paid license and manager approval:

- Adobe Creative Cloud
- Microsoft Visio and Project
- JetBrains IDEs
- Tableau

Submit a request at `https://helpdesk.acme.example` under Request > Software. Your manager approves it within 3 business days, and IT installs the software within 2 business days after approval.

## Software not in the catalog

For any application that is not in the catalog:

1. Open a request at `https://helpdesk.acme.example` under Request > New software.
2. Include the product name, the vendor website, the business reason, and the number of users.
3. The security team reviews the request. A review takes up to 10 business days.

Installing unapproved software on your own is not allowed, and local administrator rights are not granted for this purpose.

## Open-source and browser extensions

Open-source tools follow the same process as other new software. Browser extensions are limited to the list managed by IT. Ask the helpdesk if you need an extension that is not on the list.

## Removing software

Licenses that are unused for 90 days are reclaimed automatically. If you still need the application, submit a new request.
